Два приложения на языке C, которые обмениваются сообщениями по TCP.

1.  server: слушает порт 8080, принимает одного клиента, читает строки,
  отвечает эхом и дописывает каждое сообщение в файл истории.
2. client: подключается к 127.0.0.1:8080, читает строки с клавиатуры,
  отправляет серверу и печатает ответ.

Выход из чата: команда exit (клиент отправляет её серверу и завершается).

Межпроцессное взаимодействие идёт через сокеты (файловые дескрипторы):
socket, bind / listen / accept  на сервере,  connect на клиенте,
обмен данными через read / write.

Используемые библиотеки: стандартная библиотека C и POSIX API Linux.

Реализованы
•	Окружение: WSL Ubuntu, gcc
•	TCP server (socket, bind, listen, accept)
•	TCP client (socket, connect)
•	Простой чат с эхом
•	Выход по exit
•	История переписки в файле history.txt на диске
•	Базовая обработка ошибок 
•	Сборка через CMake

Структура
server.c - сервер
client.c - клиент
CMakeLists.txt - описание сборки
history.txt - появляется после запуска сервера
build - каталог сборки Cmake

Способы сборки:
Проект можно собрать двумя способами: вручную через gcc или через CMake.

1. Сборка вручную (gcc)
Зайти в папку проекта:
cd ~/lab1_ipc
Скомпилировать:
gcc server.c -o server
gcc client.c -o client
Запуск:
./server

./client

2. Сборка через Cmake
Один раз создать каталог сборки и сгенерировать файлы:
cd ~/lab1_ipc

mkdir -p build

cd build
cmake ..

Скомпилировать:
make
Запуск:
./server
./client

История чата (history.txt)

Сервер сохраняет переписку на диск в файл history.txt.

Посмотреть историю:
cd ~/lab1_ipc/build
cat history.txt или nano history.txt
Очистить: rm history.txt
